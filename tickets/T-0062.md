## Was hier gebaut wurde (SWR-127)

`pool.steckbrief_pruefen(felder)` → `(werte, auflagen)`:

| Feld | Regel | Woher |
|---|---|---|
| `auftrag` | **Pflicht** | Ohne ihn ist der Charter leer. |
| `profil` | Auswahl `entwicklung` / `dienstleistung` / `wiederkehrend` | Geschlossene Liste aus `intake.md`. |
| `rollen` | Freitext, darf leer sein | Neue Teams erfinden Rollen (`promt-team` belegt es). |
| `datenklasse` | Auswahl `offen` / `intern` / `sensibel` / `geheim` | Playbook Kap. 16. |
| `zugaenge` | Freitext, darf leer sein | Eine erfundene geschlossene Liste wäre gefährlicher als keine. |
| `grenzen` | **Pflicht** | ⚠ Das einzige Feld, in dem Schweigen die **weitere** Auslegung hat: leer wird als „keine Grenzen" gelesen. |

Bei `sensibel`/`geheim` verlässt eine **Auflage im Klartext** die Funktion als
Rückgabewert: das Repo bleibt ohne GitHub-Remote und trägt `.kein-remote`.

**Drei Entscheidungen mit Begründung:**

1. **Die Feldliste wurde hier nicht entschieden** — sie steht seit Sprint 10 mit
   Begründung je Feld im Elternticket. Dies ist die Stelle, an der sie **gilt**. Genau
   das hat SWR-125 an SWR-106 vermisst: **eine Feldliste, die kein Code prüft, ist eine
   Absichtserklärung.**
2. **Die Auflage ist ein Rückgabewert, kein Kommentar.** Die Lehre von SWR-122: eine
   Erkenntnis, die die Funktion nicht verlässt, liest niemand. Ein Test hält das fest.
3. **Keine Längengrenze daneben.** Langer Freitext läuft seit SWR-124 in eine eigene
   Datei; eine Grenze hier wäre die dritte Antwort auf dieselbe Frage (B033). Die
   Geschichte von `FELD_MAX` (200 → 4.000 → 200.000) belegt, dass die richtige Antwort
   nie eine Zahl war, sondern ein Zielort.

**Diese Funktion entscheidet nichts.** Team-Gründung ist Klasse A und bleibt beim
Menschen (Playbook Kap. 16). Geprüft wird ein **Antrag**, nicht bewilligt.
