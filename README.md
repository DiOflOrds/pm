# Projektmanagement-Team — Team-Repo

Team der Genesis-2.0-Organisation (Registry: `process/teams/registry.yaml`). Profil: **wiederkehrend** (Playbook Kap. 15). Gegründet per Klasse-A-Entscheid p0/D027, Umsetzung P5-E4.

Das PM-Team ist die Drehscheibe zwischen Mensch und allen Teams: Intake-Vorprüfung, Staffing, Session-Agenda, Wissensversorgung, Tool-Bedarf als CR ans ASPICE-Team, Lessons Learned, Eskalation nach Entscheidungsklassen (Playbook Kap. 16).

- Charter: `docs/01-team-charter.md`
- Session-Agenda: `management/session-agenda.md` (je Session gepflegt)
- Board: `BOARD.md` (generiert, `python platform/scripts/board.py pm`) — Kanban, Tickets tragen dauerhaft `sprint: 0`
- Entscheidungen (Klasse B, append-only): `management/decisions/decision-log.md`
- Briefkasten: `management/briefkasten/` (Team-Chat in Mission Control)
- Konventionen: process-Repo (Playbook Kap. 15/16), Mechanik: platform-Repo
