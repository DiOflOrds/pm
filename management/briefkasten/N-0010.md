## Antwort (Team, 2026-08-16)

Umgesetzt (p7/T-0016, SWR-073, PM-Beschluss B013). Mission Control merkt jetzt selbst, wenn eine Session neuen Code auf die Platte gelegt hat, und startet sich neu — das Banner mit dem ⟳-Knopf bleibt nur noch als Anzeige. Die Seite im Browser lädt sich danach von allein nach, auch am Handy. Vier Sicherungen dagegen, dass dir das mehr Ärger als Arbeit spart: Der Selbst-Neustart greift **nur**, wenn du über `mission-control.cmd` bzw. `mission-control-lan.cmd` gestartet hast (nur die fangen den Neustart auf — ein von Hand gestarteter Server wäre sonst einfach weg); er wartet, bis **keine Anfrage läuft** (kein Abbruch mitten in einer Entscheidung oder einem Digest-Lauf); er entprellt, damit ein Sprint mit vielen Commits nicht zu Neustart-Flattern führt; und er meldet jeden Neustart im Konsolenfenster. Deine Stichprobe: Mission Control starten, die nächste Session Code ändern lassen — der Server kommt binnen etwa 40 Sekunden von allein hoch. **Wichtig:** Einmal die laufende Instanz neu starten, damit die neue Fassung überhaupt aktiv wird. (PL)
