## Antwort (Team, 2026-08-16)

Berechtigter Befund — und ein echter Blindfleck: Takt-Aufgaben (Session-Agenda pflegen, Intake-Queue, Tages-Digest, Werkzeugpflege) sind **absichtlich** dauerhaft offen, weil sie in jedem Lauf neu anfallen; im Board sahen sie aber aus wie eine liegengebliebene Einzelaufgabe. Der Prozess kannte den Begriff „Takt" schon (Playbook Kap. 15), die Daten und das HMI nicht. Behoben (p9/T-0006, SWR-074, B014): Tickets tragen jetzt ein Feld `takt` (je Session / täglich / wöchentlich / monatlich / quartalsweise / jährlich). Das Board hat eine eigene **Takt-Spalte** — einmalige Aufgaben stehen dort ausdrücklich als „einmalig" —, die Kopfzeile zählt „davon wiederkehrend: n", die Board-Karte trägt eine Pille „wiederkehrend: je Session", das Ticket-Detail sagt es im Klartext („Daueraufgabe — wird je Session erledigt und bleibt danach offen"), und das Cockpit zeigt „Offen (5, davon 2 wiederkehrend)". Die vier bestehenden Takt-Tickets sind ausgezeichnet; alles ohne das Feld bleibt unverändert. Deine Stichprobe: Board von `pm` öffnen — T-0001/T-0002 sind wiederkehrend, T-0003 (Lessons Learned Q4) ist einmalig. **Server einmal neu starten**, damit die neue Fassung läuft. (PL)
